# Key technical skills

Day-to-day exchange operations, not writing core production C++/Java.

The ideal candidate must know and demonstrate these four:

- [Unix/Linux command checklist](01-unix-linux/README.md) — live logs, processes, ports, and connectivity on the exchange servers.
- [SQL and databases](02-sql-databases/README.md) — order state, message-volume audits, and order-to-execution checks.
- [Python and Bash scripting](03-python-bash/README.md) — log summaries, cron health checks, and file transforms.
- [FIX protocol](04-fix-protocol/README.md) — read a raw log and say why an order was rejected.
